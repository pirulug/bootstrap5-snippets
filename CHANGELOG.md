# Changelog

## Version v1.3.0 06/04/2026
- Actualizado Bootstrap a v5.3.8 en el template base.
- Añadidos nuevos snippets: Offcanvas, Carousel, Tabs y Theme Toggle (Modo Oscuro).
- Corregidos errores tipográficos en los prefijos: `bs5-spiner` -> `bs5-spinner`, `b5cardtext` -> `bs5-card-text`.
- Corregida errata en el botón del modal (`CLose` -> `Close`).
- Expandido el soporte de lenguajes a: JavaScript, TypeScript, JSX y TSX.
- Mejoras de consistencia en el uso de `$0` para la posición final del cursor.
